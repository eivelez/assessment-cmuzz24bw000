# #402: Datos ilógicos llegando al dashboard

**Status**: Open
**Assignee**: New Hire

## Síntomas

El equipo de soporte reporta que algunos dashboards muestran resultados imposibles (montos negativos, fechas raras, descuentos absurdos). Los reportes de SQL se ven bien sintácticamente, pero los datos que llegan al usuario violan reglas de negocio básicas.

Necesitamos cortar esto antes de que llegue a la interfaz de Chainlit. Habla con el equipo para alinear el alcance y la prioridad.
